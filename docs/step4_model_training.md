# LSTM 差分预测模型训练——让神经网络学习"温度扰动响应"

## 一、这个文件是做什么的？

Step 3 给了我们一堆"样本对"：

- **输入 X**：30 分钟的历史数据（36 个特征，已标准化）
- **标签 Y**：未来 30 分钟的温度变化量（差分，已标准化）

这个脚本的目标就是：

1. 把这些 NumPy 数组转成 PyTorch 的"张量"（Tensor）
2. 用批量加载器（DataLoader）每次喂 64 个样本给模型
3. 定义一个**LSTM 神经网络**，学习从"历史多变量序列"到"未来温度变化序列"的映射
4. 训练 100 轮，每轮计算预测误差、反向传播修正权重
5. 自动降低学习率、保存验证集上表现最好的模型

### 3.2 模型定义：`EnhancedLSTM`



```python
class EnhancedLSTM(nn.Module):
    def __init__(self, input_size, hidden_size, num_layers, output_len):
        super().__init__()
        self.lstm = nn.LSTM(input_size, hidden_size, num_layers,
                            batch_first=True, dropout=0.2)
        self.fc = nn.Linear(hidden_size, output_len)

    def forward(self, x):
        out, _ = self.lstm(x)
        out = self.fc(out[:, -1, :])
        return out
```

#### 技术扩展：时序神经网络架构家族






| 架构                        | 核心机制                             | 长期记忆能力             | 训练速度           | 参数量 | 可解释性                   | 适用场景                                                     |
| :-------------------------- | :----------------------------------- | :----------------------- | :----------------- | :----- | :------------------------- | :----------------------------------------------------------- |
| **LSTM（本方案）**          | 门控机制（输入门、遗忘门、输出门）   |  强（30~100步稳定）   |  中等             |  中等 |  高（门控信号可分析）   | **本方案选择**：工业中小规模时序（样本数千~数万），物理可解释性强 |
| GRU                         | LSTM 的简化版（合并为更新门+重置门） |  强（略逊于LSTM）     |  较快（少一个门） |  较少 |  中                      | 移动端/边缘端部署，需要轻量模型时                            |
| 传统 RNN                    | 简单循环                             |  极弱（>10步梯度消失）  |  快               |  最少 |  中                      |  几乎淘汰，仅教学演示                                       |
| Transformer                 | 自注意力机制                         |  极强（理论上无限长） |  慢（平方复杂度） |  极大 |  低（黑盒注意力权重）     | 超大规模数据（百万级+）、NLP、需要捕捉长程非局部依赖         |
| 1D-CNN                      | 一维卷积核滑过时序                   |  弱（受卷积核长度限制） |  极快（并行计算） |  少   |  高（卷积核即局部模式） | 局部模式识别（如振动信号故障诊断）、与 LSTM 混合使用         |
| N-BEATS / N-HiTS            | 纯全连接分解预测                     |  中等                  |  快               |  少   |  中                      | 纯时序预测（无多变量协同时）、M5 竞赛等                      |
| Temporal Fusion Transformer | LSTM + 注意力混合                    |  强                   |  慢               |  大   |  中                      | 多变量+多尺度时序预测（如零售销量预测）                      |

**为什么选择 LSTM 而非 Transformer？**

1. **数据量级**：本项目训练集仅 4015 个样本。Transformer 的注意力机制需要**海量数据**才能学到有意义的模式，小数据量下容易过拟合。
2. **序列长度**：输入仅 30 分钟。LSTM 的 30 步记忆完全够用，Transformer 的"长程优势"无处发挥。
3. **工业可解释性**：LSTM 的隐状态可以部分对应"系统惯性记忆"，工艺人员更容易接受；Transformer 的注意力权重是抽象的"谁在关注谁"，难以向操作工解释。
4. **部署成本**：LSTM 推理是顺序计算，边缘设备（工控机）上内存占用低；Transformer 的自注意力需要存储整个序列的注意力矩阵，对嵌入式不友好。

**为什么是 3 层 128 单元？**

- **3 层**：工业时序通常有"快变过程"（阀门动作，分钟级）和"慢变过程"（塔内传热，十分钟级）。多层 LSTM 可以逐层抽象：底层学局部波动，高层学长程趋势。
- **128 单元**：对于 36 维输入、30 维输出，128 是"容量充足但不浪费"的经验值。过小（32）欠拟合，过大（512）在 4015 样本上过拟合。

#### 技术扩展：批量训练策略家族






| 策略                              | Batch Size | 梯度噪声             | 内存占用 | 收敛速度                    | 适用场景                                                     |
| :-------------------------------- | :--------- | :------------------- | :------- | :-------------------------- | :----------------------------------------------------------- |
| **中等批量 32~128（本方案，64）** | 平衡       |  中等               |  中等   |  中等                      | **本方案选择**：4015 样本，64 每批 ≈ 63 步/轮，梯度噪声适中，收敛稳定 |
| 全批量 Full-Batch                 | = 总样本数 |  无噪声（精确梯度） |  极大   |  快（每步都朝最优方向）    | 极小数据集（<<1000）、凸优化问题                             |
| 随机梯度 SGD (batch=1)            | 1          |  噪声极大           |  极小   |  极慢但可能跳出局部最优    | 在线学习、非凸优化探索                                       |
| 大批量 512+                       | 大         |  噪声小             |  大     |  快（需配合学习率 warmup） | 大数据集（>10万）、分布式训练、Transformer                   |

**时序数据能不能 shuffle？** **可以，但只在"样本间" shuffle，绝不能把单个样本内部的时间步打乱。**

本项目的每个样本已经是 `(30分钟历史, 30分钟未来差分)` 的独立对。不同样本之间没有时间依赖（因为 stride=5 的滑动窗口已经把长序列切成了独立片段）。所以 `shuffle=True` 只是让模型先看到第 1000 号样本再看到第 5 号样本，不影响学习。

>  **禁忌**：如果你在做"预测下 1 分钟"的在线学习，且样本是 `(t, t+1)` 的连续单步对，那么 shuffle 会破坏时间因果。但本项目是"30 分钟窗口 → 30 分钟预测"的 Seq2Seq，窗口之间可视为独立同分布。

### 3.4 训练循环：前向、损失、反向、更新



```python
for epoch in range(1, EPOCHS + 1):
    model.train()
    train_loss = 0
    for x_batch, y_diff_batch in train_loader:
```

### 3.5 损失函数：`SmoothL1Loss`（Huber Loss）



```python
criterion = nn.SmoothL1Loss()
```

**是什么？** 一种"混合"损失函数：

- 当预测误差 `|pred - true| < 1`（默认 delta=1）时，行为像 **MSE**（二次函数，梯度随误差减小）
- 当误差 `≥ 1` 时，行为像 **MAE**（线性函数，梯度恒定，不被极端值带偏）

**公式：**



```plain
L = 0.5 * (pred - true)^2          if |pred - true| < 1
L = |pred - true| - 0.5            otherwise
```

**为什么工业场景选它？** 传感器偶尔会有尖刺（如电磁干扰导致 1 分钟温度跳变 2°C）。如果用 MSE，这个 `(2)^2 = 4` 的误差会被放大，模型被迫去拟合这个噪音，反而学歪了真实趋势。Huber Loss 对这类异常值"钝感"，让模型专注学习正常工况下的响应规律。

#### 技术扩展：回归损失函数家族






| 损失函数                       | 公式                     | 对异常值敏感度      | 梯度特性                           | 收敛速度     | 适用场景                                                 |                        |                                            |
| :----------------------------- | :----------------------- | :------------------ | :--------------------------------- | :----------- | :------------------------------------------------------- | ---------------------- | ------------------------------------------ |
| **SmoothL1 / Huber（本方案）** | 混合 MSE+MAE             |  低（delta处截断） | 小误差时梯度递减，大误差时梯度恒定 |  中等       | **本方案选择**：工业传感器有偶发尖刺，需要鲁棒性       |                        |                                            |
| MSE (L2)                       | `(pred - true)^2`        |  极高（平方放大）  | 梯度 ∝ 误差，越错越猛              |  快（初期） | 数据干净、异常值已剔除、需要严格惩罚大偏差（如金融风控） |                        |                                            |
| MAE (L1)                       | `                        | pred - true         | `                                  |  极低       | 梯度恒定为 ±1，不随误差大小变化                          |  慢（接近最优时震荡） | 异常值极多、需要中位数回归、可接受较慢收敛 |
| Log-Cosh                       | `log(cosh(pred - true))` |  低（类似 Huber）  | 平滑可导，处处连续                 |  中等       | 竞赛刷分、需要处处二阶可导                               |                        |                                            |
| Quantile Loss                  | 分位数加权绝对误差       |  低                | 不对称梯度                         |  中等       | 需要预测区间（如"80%置信度下温度不超过42°C"）            |                        |                                            |

### 3.6 学习率调度：`ReduceLROnPlateau`



```python
scheduler = torch.optim.lr_scheduler.ReduceLROnPlateau(optimizer, mode='min', factor=0.1, patience=5)
scheduler.step(val_loss)
```

**是什么？** 一个"教练"：如果验证 Loss 连续 5 轮（patience=5）都没有下降，就把学习率乘以 0.1（factor=0.1），让模型迈更小的步子，精细搜索最优解。

**为什么需要？** 训练初期，学习率 0.001 能快速接近最优区域。但到了后期（如 Epoch 15 后），Loss 在 0.0003 附近震荡，大步子会在"山谷"两侧来回跳。降低学习率后，模型像显微镜一样精细打磨权重。

#### 技术扩展：学习率调度策略家族






| 策略                            | 触发条件                    | 学习率变化        | 优点                                   | 缺点                              | 适用场景                                                     |
| :------------------------------ | :-------------------------- | :---------------- | :------------------------------------- | :-------------------------------- | :----------------------------------------------------------- |
| **ReduceLROnPlateau（本方案）** | 验证指标停滞                | ×0.1（断崖式）    | 按需调整，不浪费 Epoch                 | 超参敏感（patience/factor）       | **本方案选择**：工业模型训练，验证集是真实未来的代理，指标停滞即降 LR |
| StepLR                          | 固定 Epoch 间隔             | ×gamma（每 N 轮） | 简单无脑                               | 可能在不必要时降 LR，或该降时不降 | 已知收敛曲线形态（如图像分类）                               |
| CosineAnnealingLR               | 每轮按余弦曲线衰减          | 周期波动下降      | 理论上能跳出局部最优                   | 需设 T_max，与总 Epoch 耦合       | 大 Epoch 训练（>200轮）、竞赛刷分                            |
| OneCycleLR                      | 先升后降一个周期            | 单峰曲线          | 收敛极快，泛化好                       | 需配合大 Batch Size，超参难调     | 快速原型、有充足算力调参                                     |
