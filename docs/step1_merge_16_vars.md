# 📘 step1_merge_16_vars 教学文档：

# 工业多源 CSV 数据清洗与宽表合并

## 一、这个文件是做什么的？

想象你是一个工厂的数据工程师。现场有 13 台传感器，每台传感器每分钟都在往电脑里存一个 `.csv` 文件，记录"温度""压力""流量"等数据。这些文件格式混乱，有的带质量戳（比如用 `192` 表示"数据无效"），有的列名不统一。

**这个脚本的目标就是：**

1. 把这 13 个文件全部读进来
2. 把"时间"和"数值"自动找出来
3. 把"垃圾数据"（质量戳）扔掉
4. 按时间对齐，拼成一张"大宽表"（每一行是一个时间点，每一列是一个传感器）
5. 统一重采样到"每 1 分钟一条"，存成高性能文件

------

## 二、整体流程图（文字版）

plain



```plain
13个CSV文件
    ↓
逐个读取：找时间列、找数值列、扔掉垃圾值
    ↓
13个独立的小表格（每个只有2列：时间 + 一个变量）
    ↓
按时间轴"横向拼接"成宽表（13列 + 1个时间索引）
    ↓
处理缺失值（前向/后向填充）
    ↓
重采样到1分钟均值
    ↓
保存为 merged_wide_table.parquet
```

**知识点卡片：**

| 代码                      | 是什么                | 小白解释                                                     |
| :------------------------ | :-------------------- | :----------------------------------------------------------- |
| `df_temp.columns`         | 获取表格的所有列名    | 返回一个类似列表的东西，里面装着 `'datetime'`、`'datavalue'`、`'quality'` 这样的字符串。 |

#### 3.3.5 数据清洗：干掉质量戳，填上缺失值

Python

```python
    df_selected[col_name] = pd.to_numeric(df_selected[col_name], errors='coerce')
    df_selected = df_selected.dropna().ffill().bfill()
```

**这是整个 Step 1 最关键、最容易被忽视的三行代码。**

**知识点卡片：**

表格

| 代码                                  | 是什么                         | 小白解释                                                     |
| :------------------------------------ | :----------------------------- | :----------------------------------------------------------- |
| `pd.to_numeric(..., errors='coerce')` | 强制转成数字，转不了的变 `NaN` | 工业数据里经常混着**质量戳**（如 `192` 表示"通信正常但数值无效"）。`to_numeric` 尝试把每个值变成浮点数；如果碰到 `192` 这种"长得像数字但实际是状态码"的情况……等等，`192` 其实是能转成数字的！<  ⚠️ **注意**：这里的 `192` 在原始 CSV 里通常是**字符串** `'192'` 或者确实就是数值 `192`。如果它是数值 `192`，`to_numeric` 不会报错，会保留 `192.0`。但结合上下文，原始数据里的 `192` 可能是**质量戳字符串**（如 `'192'` 作为状态码），或者代码注释想表达的是"非数值的标记"。<  更常见的情况是：有些系统用 `'Bad'`、`'Error'`、`'###'` 表示无效，这时 `to_numeric` 就会把它们变成 `NaN`（Not a Number，缺失值）。 |
| `errors='coerce'`                     | 强制策略                       | 遇到转不了的，不报错，直接变成 `NaN`。                       |
| `.dropna()`                           | 删除包含 `NaN` 的行            | 把刚才产生的缺失值整行删掉。                                 |
| `.ffill()`                            | **前向填充**（forward fill）   | 用**上一个有效值**往下填。比如 `[40.0, NaN, NaN, 40.2]` → `[40.0, 40.0, 40.0, 40.2]`。适合工业传感器短暂断线的情况。 |
| `.bfill()`                            | **后向填充**（backward fill）  | 用**下一个有效值**往回填。和 `ffill` 连用，确保开头如果有缺失也能被填满。 |

**为什么工业数据要 ffill + bfill？** 因为传感器偶尔丢包 1~2 分钟，温度不可能突变。用前后的真实值填充，比直接删行或填 0 更合理。

> 💡 **学习推荐**：数据清洗是工业项目的**体力活+核心活**。建议系统学习 **pandas 数据清洗（缺失值处理、异常值检测、数据类型转换）**。重点掌握：`isnull()`、`fillna()`、`dropna()`、`astype()`、`to_numeric()`。

#### 3.4.1 横向拼接：时间对齐

Python



```python
    df_wide = pd.concat(all_dfs, axis=1, join='outer')
    df_wide = df_wide.ffill().bfill()
    df_wide = df_wide.resample('1min').mean().ffill()
    df_wide = df_wide.dropna()
```

**这是整个 Step 1 的核心，四行代码做四件大事。**

**知识点卡片：**

表格

| 代码                                       | 是什么               | 小白解释                                                     |
| :----------------------------------------- | :------------------- | :----------------------------------------------------------- |
| `pd.concat(all_dfs, axis=1, join='outer')` | **横向拼接**多个表格 | `axis=1` 表示"左右拼"（增加列）；`axis=0` 是"上下拼"（增加行）。<  `join='outer'` 是**外连接**：只要某个时间点任意一张表有数据，就保留这一行；缺失的列填 `NaN`。与之对应的是 `'inner'`（内连接，只保留所有表都有数据的时间点）。<  工业场景用 `outer`，因为不同传感器采样时刻可能差几秒，不能简单粗暴地只保留"完全对齐"的行。 |
| `.ffill().bfill()`                         | 再次填充缺失值       | 拼接后，某些传感器在特定时间点没数据（因为采样时刻差了几秒），用前后值填充。 |
| `.resample('1min').mean()`                 | **重采样到 1 分钟**  | 这是**时间序列的专属操作**。因为原始数据可能是"每秒一条"或"每 10 秒一条"，不统一。`resample('1min')` 把时间切成 1 分钟一个桶，`.mean()` 取每个桶里的平均值，让所有数据统一变成"每分钟一条"。 |
| `.dropna()`                                | 最后删去仍有缺失的行 | 如果某个时间点所有传感器都没数据（极端情况），整行删掉。     |

**为什么重采样用 `mean()`？** 因为 1 分钟内温度/压力可能波动 3~5 次，取均值比取最后一个值更能代表这一分钟的真实状态，也更有抗噪性。

> 💡 **学习推荐**：`pd.concat` 和 `resample` 是 pandas 进阶操作。建议学习：
>
> 1. **pandas 数据合并（merge, join, concat）**：理解 `axis`、`join` 参数
> 2. **pandas 时间序列重采样（resample, asfreq, interpolate）**：理解 `rule` 字符串（`'1min'`、`'5min'`、`'1H'`）

## 五、常见坑点与自查清单

表格

| 坑点                               | 现象                                        | 排查方法                                            |
| :--------------------------------- | :------------------------------------------ | :-------------------------------------------------- |
| CSV 列名大小写不一致               | `value_cols` 为空，报错"未找到 value 列"    | 打印 `df_temp.columns.tolist()` 查看实际列名        |
| 时间格式不标准                     | `pd.to_datetime` 报错或解析错误             | 先 `print(df['time'].head())` 看原始格式            |
| 质量戳是数值（如 192.0）而非字符串 | `to_numeric` 不会把它变 NaN，导致均值被拉高 | 需要额外做异常值判断（如 `df[df > 1000] = np.nan`） |
| 不同传感器时间戳差几秒             | `concat` 后产生大量 NaN                     | 确认 `resample('1min')` 是否已执行                  |
| 原始数据不是 1 分钟间隔            | 重采样后行数变少/变多                       | 对比 `len(df_raw)` 和 `len(df_resampled)`           |
